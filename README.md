# symb（双语模板）

一两步出品的双语排版工具。输入标题和中文正文，即时生成中英双语笔记；也可以从电脑上传图片、进行 OCR 识别，并下载 Markdown、PNG 或 ZIP。

公开使用地址：<https://symb.pages.dev>

编辑区采用左右双栏实时渲染：左侧输入中文后，右侧会立即更新模板内容，停顿片刻后自动刷新英文。

成品 PNG 固定为 1080×1440：有图片时使用“顶部整幅插画 + 英文标题 + 中文大标题 + 双语要点”版式；无图片时使用“顶部徽章/标题 + 灰色横线 + 左英文右中文双栏正文”版式，左右正文按对应段落成组对齐。

工作台可以单独填写中文标题与 IP 品牌名；品牌名会统一常驻每页顶部徽章与底部署名。标题会独立翻译，并同步到右侧预览、PNG、ZIP 和 Markdown。正文按实际排版高度智能生成，整组笔记控制在 3–6 页。

封面支持在右侧直接按住拖动取景，并可调节图片高度（30%～75%）和缩放比例（100%～220%）。正文支持 11px～16.5px 字号及 1.35～1.90 行高微调；参数变化会重新计算分页并保留底部安全边距。

生成完成后，将鼠标移到右侧卡片上即可“复制本张”或“下载本张”。复制功能会以 3 倍清晰度生成 PNG 并写入系统剪贴板，可直接粘贴到支持图片粘贴的平台。

上传的封面图片默认完整显示，不会被直接裁掉；右侧图片区域可以按住拖动调整位置，双击图片恢复居中，预览位置会同步到当前页 PNG 和 ZIP 成品。

## 启动

```bash
npm start
```

然后打开 <http://localhost:5173>。

页面会优先尝试在线翻译；如果网络翻译不可用，会自动切换到内置的本地备用引擎。上传图片后点击生成，会在浏览器内加载项目自带的中文 OCR 引擎识别图片，不会把图片上传到 OCR 第三方服务；中文识别模型首次使用时会占用约 20MB。英文翻译文本会请求在线翻译服务。

每次按内容长度智能生成 3–6 页。ZIP 包内包含全部页面 PNG、完整 Markdown 和 README.txt。
